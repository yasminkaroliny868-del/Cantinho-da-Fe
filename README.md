# Cantinho da Fé 💙

O Cantinho da Fé é uma loja virtual de artigos religiosos católicos, criada como projeto acadêmico.

## Sobre o projeto

O objetivo é apresentar produtos religiosos de forma simples, bonita e organizada, proporcionando uma experiência agradável aos visitantes.

## Produtos disponíveis

- Terços
- Bíblias
- Crucifixos
- Medalhas
- Imagens de Santos

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Exibição dos produtos.
- Seleção de produtos e quantidades.
- Validação dos campos.
- Carrinho de compras demonstrativo.
- Armazenamento de informações com localStorage.
- Mensagem informando se a loja está aberta ou fechada.

## Autoria

Projeto desenvolvido para fins acadêmicos.
